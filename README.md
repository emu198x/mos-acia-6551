# mos-acia-6551

The MOS 6551 asynchronous communication interface adapter.

| Crate | Registry |
|---|---|
| [`emu198x-mos-acia-6551`](crates/emu198x-mos-acia-6551) | [crates.io](https://crates.io/crates/emu198x-mos-acia-6551) |

Part of [Emu198x](https://github.com/emu198x/emu198x), a family of
cycle-accurate retro-computing emulators. Used by the Dragon 64 and the Oric Atmos's serial card.

Each crate is versioned on its own and bumps only when it changes. Releases go
through release-plz: merging its release pull request tags the crate and
publishes it.
